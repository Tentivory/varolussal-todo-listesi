# Varoluşsal Todo Listesi

## Bu Nedir?

Bu, dünyanın en ciddi ve en saçma todo listesi uygulamasıdır. Her eklediğin görev, senin varoluşunu sorgulamanı sağlar. Gerçekten çalışır. Python ile yazıldı. Neden Python? Çünkü yılanlar da sorgular.

## Nasıl Kullanılır?

1. Python 3 kurulu olsun (yoksa neden yok diye sorgula).
2. `python todo.py` çalıştır.
3. Görev ekle, listele, çık. Ama her adımda pişman ol.

### Örnek
```
> ekle dünyayı kurtar
Neden bu görevi yapıyorsun? Gerçekten gerekli mi yoksa alışkanlık mı?
Görev eklendi: 'dünyayı kurtar' - ama neden ekledin ki?
> listele
1. dünyayı kurtar (neden?)
> çık
Çıkıyorsun... ama gerçekten çıkıyor musun yoksa kaçıyor musun?
```

## Neden Bu Repo?

Çünkü normal todo listeleri çok ciddi. Biz ise abartılı ciddiyiz. Bu repo, absürtlüğün zirvesidir. Katkıda bulunmak istersen, önce neden katkıda bulunmak istediğini sorgula.
